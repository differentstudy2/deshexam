# DeshExam - Premium Exam Preparation Platform

DeshExam is a comprehensive, AI-powered educational platform built with Next.js, tailored for Indian competitive exams like NEET, JEE, UPSC, and school-level textbook solutions.

## 🚀 Key Features

- **Dynamic Mock Tests & Quizzes**: Realistic exam simulations with timers, instant results, and performance tracking.
- **AI Learning Path**: Personalized study plans generated by Gemini AI based on user performance.
- **Textbook Solutions**: Step-by-step solutions for NCERT and other major boards, organized by chapters and topics.
- **Kids Zone**: Interactive learning modules for languages (Bengali, Hindi, English, Arabic, Urdu) and basic math.
- **Community Q&A**: A robust platform for students to ask and answer questions, featuring a point-based leaderboard.
- **Advanced SEO**: Fully optimized for search engines with dynamic sitemaps, robots.txt, and structured data (JSON-LD) for all educational resources.
- **Monetization Ready**: Integrated with Google AdSense and Razorpay for premium subscriptions (Pass/Pass Pro).

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **UI Components**: [Shadcn UI](https://ui.shadcn.com/) & [Tailwind CSS](https://tailwindcss.com/)
- **Backend/Database**: [Firebase](https://firebase.google.com/) (Firestore, Auth, Storage)
- **AI Integration**: [Genkit](https://firebase.google.com/docs/genkit) with Google Gemini
- **Payments**: [Razorpay](https://razorpay.com/)

## 📦 Deployment & GitHub Connection

This project is configured for **Firebase App Hosting**. 

### Pushing Changes
To push your changes to GitHub, use the following commands in your terminal:
1. `git add .`
2. `git commit -m "Your descriptive message"`
3. `git push origin main`

### Reconnecting GitHub
If you need to disconnect and reconnect your GitHub repository:
1. Go to the **Firebase Console**.
2. Select your project.
3. Navigate to **App Hosting** in the left sidebar.
4. Select your backend and go to the **Settings** tab.
5. Under **Deployment**, you can manage the GitHub connection (Disconnect/Reconnect).
6. Ensure that the `GCP_SA_KEY`, `FIREBASE_PROJECT_ID`, and `GEMINI_API_KEY` secrets are correctly set in your GitHub repository secrets if you recreate the connection.

## 📈 SEO & Discovery
