# DeshExam - Premium Educational Platform

DeshExam is a comprehensive, AI-powered educational platform tailored for competitive exams (like NEET, JEE, UPSC) and school-level textbook solutions in India. Built with a modern Next.js architecture, it provides an engaging experience for students and a robust management dashboard for administrators.

## 🚀 Key Features

### 🎓 Student Modules
- **Dynamic Mock Tests & Quizzes**: Realistic exam simulations with timers, instant results, and performance tracking.
- **AI Learning Path**: Personalized study plans generated by Google Gemini via Genkit based on user performance.
- **Textbook Solutions**: Step-by-step solutions for NCERT and other major boards, organized by chapters and topics.
- **Classes & Academy**: Structured courses and educational content.
- **Kids Zone**: Interactive learning modules for early education (languages: Bengali, Hindi, English, Arabic, Urdu and basic math).
- **Documents & Media Reader**: Built-in support for reading PDFs (invoices, study materials), playing educational audio and videos directly in the app.
- **Community Q&A**: A platform for students to ask questions, help others, and earn points on the Leaderboard.
- **Premium Subscriptions**: Integrated with Razorpay for Pass/Pass Pro monetization.

### 🛡️ Admin Dashboard (`/admin`)
A fully-featured backend interface for platform managers to control all aspects of the app:
- **Content Management**: Add, edit, and organize Articles, Exams, Quizzes, Textbooks, Practice Questions, Videos, and Kids Zone modules.
- **Document Management**: Centralized hub for managing PDF collections and uploaded files.
- **User & Revenue Control**: Track earnings, manage user accounts, and generate/distribute coupons.
- **Engagement**: Send push notifications to users.
- **Analytics & Reports**: Comprehensive dashboards for tracking platform usage and revenue.

## 🛠 Tech Stack & Architecture

### Frontend
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [Shadcn UI](https://ui.shadcn.com/) (Radix Primitives)
- **Rich Text Editor**: [TipTap](https://tiptap.dev/) (with extensions for YouTube, Math via KaTeX, Tables, etc.)
- **PDF Viewing**: `react-pdf`, `pdfjs-dist`
- **Data Visualization**: `recharts`
- **Media**: `react-player`

### Backend & Infrastructure
- **Database & Auth**: [Firebase](https://firebase.google.com/) (Firestore, Storage, Firebase Authentication)
- **AI Integration**: [Genkit](https://firebase.google.com/docs/genkit) + Google Gemini API (`@genkit-ai/google-genai`)
- **Payments**: [Razorpay](https://razorpay.com/)
- **Deployment**: Configured for **Firebase App Hosting**

## 💻 Getting Started (Development)

### Prerequisites
- Node.js (v18 or higher)
- A Firebase Project (with Firestore, Storage, and Auth enabled)
- Razorpay Account (for testing payments)
- Gemini API Key

### Installation

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd deshexam
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Environment Variables:**
   Create a `.env.local` file in the root directory and add your keys (refer to `next.config.ts` or usage in `src/lib/firebase` for exact variable names):
   ```env
   NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
   NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
   
   FIREBASE_CLIENT_EMAIL=your_firebase_admin_client_email
   FIREBASE_PRIVATE_KEY="your_firebase_admin_private_key"
   
   RAZORPAY_KEY_ID=your_razorpay_key
   RAZORPAY_KEY_SECRET=your_razorpay_secret
   
   GEMINI_API_KEY=your_gemini_api_key
   ```

4. **Run the Development Server:**
   ```bash
   npm run dev
   # Server will start on http://localhost:9002
   ```

5. **Run Genkit (AI Development):**
   ```bash
   npm run genkit:dev
   ```

## 📦 Deployment & Git Workflow

This project uses **Firebase App Hosting** for seamless deployment integrated with GitHub.

### Pushing Changes
1. `git add .`
2. `git commit -m "Your descriptive message"`
3. `git push origin main`

Firebase App Hosting will automatically detect pushes to the `main` branch and trigger a new build and deployment.

### 🔧 Git Troubleshooting (Non-fast-forward error)
If your `git push` is rejected:
1. `git pull origin main --rebase`
2. Resolve any conflicts, then `git add .` and `git rebase --continue`.
3. `git push origin main`

### Managing App Hosting Connection
1. Go to the **Firebase Console** -> **App Hosting**.
2. Select your backend -> **Settings** tab.
3. Manage your GitHub connection (Disconnect/Reconnect) under **Deployment**.
4. **Important**: Ensure `GCP_SA_KEY`, `FIREBASE_PROJECT_ID`, and `GEMINI_API_KEY` secrets are correctly set in the Google Cloud Secret Manager linked to App Hosting.
